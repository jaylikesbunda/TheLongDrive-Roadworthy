# Experimental multiplayer parity matrix

Status is deliberately conservative: none of the experimental features below is wired into the game or verified in a multiplayer session. Native/Roadworthy baseline requires actual recorded host and guest runs. Offline tests establish only the stated isolated contracts. Details and native hook references: `MULTIPLAYER_MESSAGE_INVENTORY.md`, `MULTIPLAYER_MODE_BOUNDARY_INVENTORY.md`, `MULTIPLAYER_VEHICLE_SLICE_INVENTORY.md` and `REVAMP_MULTIPLAYER_LESSONS.md`.

| Capability / scenario | Experimental work so far | Required evidence before enabling |
|---|---|---|
| Mode select, reject mismatch, disconnect/rehost | Misc selector + persisted `mpmode` option, `TLD_MP_EXPERIMENTAL` override, mode-tagged `StableNode` signature so native and experimental peers reject at Hello, authority state reset on teardown | A real two-instance run of the selector lock and mismatch rejection; lobby-metadata mode field still absent |
| Steam membership, handshake, replays and delivery | Bounded offline framing, issuer, admission and per-channel sequence prototypes; experimental mode reuses the native session/relay | Two authenticated Steam accounts; host/guest reversal, lobby spoof/mismatch, retry, stale challenge and transport channel semantics |
| World seed/options and generation | Not implemented | Same world, starting options and generation under origin shifts and mod/content mismatch |
| Player body, animation, seats and held items | Not implemented | Join, seat, passenger, departure, late join, reconnect and separation |
| Vehicle pose | Read-only adapter, standalone codec and owner/epoch admission; no game hooks or replica | Actual two-machine driver, observer, independent origin shifts, jitter/loss and visual/physics behavior |
| Vehicle authority and collision | Host-side ownership is enforced in the live relay: the highest native car role owns pose/velocity, non-owner samples are dropped and not relayed, and grants are broadcast reliably with epochs. Offline model tests plus the full native regression gate pass. | A real two-instance driver/passenger run; handoff, simultaneous claims, crash and owner disconnect |
| Attachments, containers and cargo | Offline graph/identity prototypes; ID/reference preflight and detached-copy remap exercised with native save types | Atomically reserve ranges, verify full native-copy fidelity, validate all records/external references, apply complete remapping, mounted/stored/loose/held distinctions, transfer and streaming, no duplicates/loss |
| POI and dynamic spawning | Not implemented | One spawn per world/POI; interrupted spawn, contested arrival and persistent spawn decisions |
| Item state, interactions, fluids, damage and weapons | Not implemented | Each native message/interaction mapped, reliable dependency ordering and test after late join and reload |
| POI doors, time, radio, weather, wildlife | Not implemented | Host/guest interactions, separated players, unload/reload and Roadworthy additions |
| Streaming, local identity and object deletion | Offline binding generation/tombstone tests only | Actual far-store update and recreation, old callbacks, local-ID collisions and stale packets |
| Join snapshot and journal | Offline bounded reassembly, session-checked receiver and bounded revision-journal prototypes; no snapshot capture or game integration | Coherent snapshot plus events, Steam-authenticated host binding, aggregate multi-session budgets, sequencing, bounded transfer, cancellation, incomplete construction and rollback/failure behavior |
| Save, reload, autosave and recovery | Not implemented | Consistent saved world, remote-owner cut, guest-save isolation, interrupted writes and autosave rotation |
| Multi-hour and three-player sessions | Not implemented | Real two/three-account tests, loss/reorder, long distances, performance, no object or save corruption |

Integration blockers found in prototype review: entity authority, graph and local identity are separate stores without a transactional spawn/removal coordinator; none enforces a session-wide entity/tombstone/rate budget. Vehicle validation checks finite values and ownership but not plausible speed, displacement or authorized teleport. Handoff acknowledgements are not yet bound to an authenticated transaction's applied snapshot. Every mutable prototype requires a single session thread. Connection validators must be pure, and reliable invalid/gap results require an explicit retry or termination policy. Completed snapshot leases require strict consumer ownership and disposal; a consumer must not retain their byte array after disposal.

Offline integration since that review (still not wired to the game): `ExperimentalCoordinator.cs` now owns the graph, authority and identity stores, so spawn and removal are all-or-nothing across all three, live and tombstone counts are bounded, an unexpected partial update fails closed into a required rekey, mutations are host-only and thread-owned, and ID reuse after removal is impossible. `ExperimentalHandoff.cs` now requires authenticated source and target sessions, binds the target acknowledgement to a 32-byte digest of the applied state, and aborts plus unfreezes on deadline. `ExperimentalPolicy.cs` gates message kinds by sender role and channel; `ConnectionGuard` gained a role-aware form while its legacy form is unchanged. The digest is caller-supplied, not produced by a world capture, and no transport, lobby or game hook consumes any of this yet.

Integrated slice (2026-11-05, installed test build): `ExperimentalBackend.cs` is part of the normal runtime and the IL patch. The backend reuses the native relay for session/join/players/items, adds host-issued vehicle-motion ownership, persists the mode in `roadworthy-options.txt` with a locked Misc selector, and tags the session signature so mixed-mode peers fail at Hello before any world mutation. `pathscript.path()` is rewritten to `StableGameBridge.RedirectSaveRoot`, which moves the whole save/settings/map/log tree under `TLD_MP_SAVE_ROOT` for test instances and reproduces the native Documents path when unset. This slice is installed and offline-verified; live loopback gameplay is still pending.

The detached fixture now normalizes native weapon copies, preserves absent nested components, and remaps validated embedded weapon, part-color and meter-owner IDs. It preserves empty meter/outfit/ragdoll/bus-door/random-scale arrays, rejects unsafe null/mismatched shapes, and checks tank array lengths. Null/empty revolver ammunition and inconsistent nested ownership are rejected. Some legitimate records may be rejected until prefab-aware validation is available. No prefab or full component-semantic validation exists yet, so the isolated fixture is not vehicle parity.

Run `tests/scripts/Test-Experimental.ps1` for isolated model tests, `tests/scripts/Test-ExperimentalGameCompile.ps1` to compile the read-only adapters, and `tests/scripts/Test-ExperimentalNativeRecords.ps1` for detached-record tests using the installed game's actual types and `RearrangeID`. These checks do not run the game, read player saves or enable experimental multiplayer. The native remap test covers a small detached graph only; it does not establish atomicity, spawning or full component parity. The normal patch build deliberately does not include these development sources yet.
